# tests ── 決めたことの番人

**このフォルダは「決めたことが消えていないか」を機械で確かめるためのものです。**

2026-08-18、ひろみさんの「**これ、また数時間で消えない？**」という問いへの答えとして、
それまで作業場所にしか無かったテストを、ここ（リポジトリの中）に移しました。
**作業場所は数時間で消えますが、ここは消えません。**

## 使い方（1行だけ）

```
node tests/すべて試す.js
```

これだけです。最後にこう出れば大丈夫です。

```
  ✅ 全部そろっています。決めたことは消えていません。
```

**1つでも `★` が出たら、決めたことのどれかが壊れています。** そのまま知らせてください。

## いつ走らせるか

- **コードを触る前**（＝いまが正しい状態かを確かめてから始める）
- **納品する前**（＝壊していないことを確かめてから渡す）

この2回です。1つでもFAILがあるまま渡してはいけません。

## 大事な決まり

- **テストは、本番のファイルから本物の関数をそのまま切り出して動かします。**
  テスト用に書き直した別物ではありません。だから「テストは通るのにアプリは壊れている」が起きません。
- **本番のデータには一切書き込みません。** 作り物の在庫・作り物の注文だけを使います。
- **GASのファイルはここに置いていません**（パスワードとLINEのIDが入っているため）。
  手元の `olive-stories-gas`（`clasp pull` で作られる）にあれば読み、無ければそのテストは飛ばします。

## 直したら、ここも足す

新しく決めごとを作ったら、**必ずここにテストを1つ足してください。**
テストが無い決めごとは、次に誰かが触ったときに消えます。

`すべて試す.js` の一覧にも1行足すのを忘れずに。
